# ISO 20022 pain.001 - Customer Credit Transfer Initiation

Documentation du standard ISO 20022 pain.001.001.12 utilisé dans Smart Mapping Platform.

---

## 📋 Vue d'Ensemble

**Nom complet :** `pain.001.001.12` - Customer Credit Transfer Initiation  
**Domaine :** Paiements (Payments Initiation)  
**Version :** 001.12 (Mars 2024 - version la plus récente)  
**Format :** XML  
**Usage :** Initiation de virements bancaires

---

## 🎯 Objectif du Standard

Le message **pain.001** permet à un donneur d'ordre (client ou entreprise) d'instruire sa banque pour effectuer un ou plusieurs virements vers des bénéficiaires.

**Cas d'usage typiques :**
- Virement unique client à client
- Virements de masse (salaires, fournisseurs)
- Paiements internationaux
- Virements SEPA
- Paiements domestiques

## 🏗️ Structure du Message

### Schéma Hiérarchique
```
pain.001.001.12
│
├── CstmrCdtTrfInitn (Customer Credit Transfer Initiation)
│   │
│   ├── GrpHdr (Group Header) ⭐ MANDATORY
│   │   ├── MsgId - Identifiant unique du message
│   │   ├── CreDtTm - Date/heure de création
│   │   ├── NbOfTxs - Nombre de transactions
│   │   └── CtrlSum - Somme de contrôle (optionnel)
│   │
│   └── PmtInf (Payment Information) ⭐ MANDATORY [1..*]
│       │
│       ├── PmtInfId - ID information de paiement
│       ├── PmtMtd - Méthode (TRF = Transfer)
│       ├── ReqdExctnDt - Date d'exécution demandée
│       │
│       ├── Dbtr (Debtor) ⭐ MANDATORY
│       │   ├── Nm - Nom
│       │   └── PstlAdr - Adresse postale
│       │       ├── StrtNm - Rue
│       │       ├── BldgNb - Numéro
│       │       ├── PstCd - Code postal
│       │       ├── TwnNm - Ville
│       │       └── Ctry - Pays (ISO 3166)
│       │
│       ├── DbtrAcct (Debtor Account) ⭐ MANDATORY
│       │   ├── Id.IBAN - IBAN du compte émetteur
│       │   └── Ccy - Devise (optionnel)
│       │
│       ├── DbtrAgt (Debtor Agent) - Banque émettrice
│       │   └── FinInstnId.BIC - Code BIC
│       │
│       └── CdtTrfTxInf (Credit Transfer Transaction Info) ⭐ MANDATORY [1..*]
│           │
│           ├── PmtId (Payment Identification)
│           │   ├── InstrId - Instruction ID
│           │   └── EndToEndId - End-to-End ID
│           │
│           ├── Amt (Amount) ⭐ MANDATORY
│           │   └── InstdAmt - Montant (+ attribut Ccy)
│           │
│           ├── Cdtr (Creditor) ⭐ MANDATORY
│           │   ├── Nm - Nom bénéficiaire
│           │   └── PstlAdr - Adresse
│           │
│           ├── CdtrAcct (Creditor Account) ⭐ MANDATORY
│           │   └── Id.IBAN - IBAN bénéficiaire
│           │
│           ├── CdtrAgt (Creditor Agent) - Banque bénéficiaire
│           │   └── FinInstnId.BIC - Code BIC
│           │
│           └── RmtInf (Remittance Information) - Info de remise
│               └── Ustrd - Non structuré (texte libre)
```

## 🔑 Éléments Clés

### Identifiants

**MsgId (Message ID)**
- Identifiant unique du message
- Doit être unique par émetteur
- Format libre mais recommandé : préfixe + date + séquence

**EndToEndId (End-to-End ID)**
- Identifiant de bout en bout
- Transmis de bout en bout (émetteur → bénéficiaire)
- Permet le rapprochement comptable

### Codes Standards

**PmtMtd (Payment Method)**
- `TRF` - Transfer (virement)
- `CHK` - Cheque
- `TRA` - Draft

**Ccy (Currency)** - ISO 4217
- `TND` - Dinar Tunisien
- `EUR` - Euro
- `USD` - Dollar US

**Ctry (Country)** - ISO 3166-1 alpha-2
- `TN` - Tunisie
- `FR` - France
- `US` - États-Unis

## ✅ Règles de Validation

### Champs Obligatoires
- Message ID
- Date création
- Nom émetteur
- IBAN émetteur
- Nom bénéficiaire
- IBAN bénéficiaire
- Montant

### Formats
- IBAN : selon pays (24 caractères pour TN)
- BIC : 8 ou 11 caractères
- Date : ISO 8601
- Montant : max 2 décimales

### Contraintes Business
- Montant > 0
- Date exécution >= Date création
- IBAN valide (checksum)
- BIC valide

## 🌍 Contexte International

### SEPA (Single Euro Payments Area)
Le pain.001 est utilisé pour les virements SEPA en Europe.

### SWIFT
Compatible avec les messages SWIFT MT103 (équivalent).

### Banque Centrale de Tunisie (BCT)
Format accepté pour les paiements interbancaires en Tunisie.
